# Learning Notes

This repository is a small sandbox for practicing Git and GitHub.

## Practice areas

- Creating and updating repositories
- Working with branches
- Writing useful commit messages
- Reviewing pull requests
- Organizing Markdown documentation
- Keeping experiments isolated from production projects

## Git workflow

1. Create a focused branch.
2. Make a small, understandable change.
3. Review the diff.
4. Commit with a descriptive message.
5. Push the branch.
6. Open a pull request when collaboration or review is useful.

## Principle

Keep experiments small enough that the purpose of each change is easy to understand.
