# Issue Guidelines

Use issues when a change needs discussion, tracking, or a reproducible bug report.

## Useful issue format

### Problem

Describe what is wrong or what needs to change.

### Reproduction

For a bug, list the smallest steps that reproduce it.

### Expected behavior

Explain what should happen.

### Actual behavior

Explain what happened instead.

### Scope

Keep the issue focused enough to close with a clear outcome.
