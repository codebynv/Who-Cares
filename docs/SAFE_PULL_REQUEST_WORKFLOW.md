# Safe Pull Request Workflow

1. Start from an up-to-date base branch.
2. Create a focused working branch.
3. Make the smallest change that solves the issue.
4. Inspect the complete diff before staging.
5. Run relevant checks when available.
6. Explain the change and actual validation in the pull request.
7. Address review feedback before merging.

Avoid force-pushing shared branches or merging changes that have not been reviewed.
